# Simplified user flow

The intended field flow for 0.4.1 is intentionally short:

1. With the phone hotspot on, save the hotspot/controller IP once.
2. Turn the hotspot off and join the strip setup Wi-Fi.
3. Return to FG Machines RCK and press the green Continue button once.
4. Turn the same hotspot back on when Android opens hotspot settings.

No second phone, router, Korean subscription or manual IP entry is required after the hotspot IP has been saved.
